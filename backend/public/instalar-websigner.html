🖊️ Guía de Instalación - WebSigner ePad

Instrucciones completas para instalar y configurar la extensión WebSigner

📋 Paso 1: Verificar Requisitos del Sistema

Antes de instalar la extensión, asegúrate de que tu sistema cumple con los requisitos:

  • Sistema Operativo: Windows 7 o superior, macOS 10.12+, Linux
  • Navegador: Chrome 30+, Firefox 30+, Edge 12+, Safari 8+
  • Dispositivo ePad: Conectado y reconocido por el sistema

🔧 Paso 2: Instalar el Software ePad

Primero necesitas instalar el software base del ePad:

⚠️ Importante: El software del ePad debe instalarse ANTES que la extensión del navegador.

Descargar e instalar:

📥 Descargar ePadLink SigCaptureWeb SDK

Después de la descarga:

  1. Ejecuta el archivo SigCaptureWeb.exe como administrador
  2. Sigue las instrucciones del instalador
  3. Reinicia tu computadora si es necesario
  4. Conecta tu dispositivo ePad

🌐 Paso 3: Instalar la Extensión del Navegador

Elige tu navegador y sigue las instrucciones correspondientes:

Google Chrome

  1. Abre Chrome y ve a Chrome Web Store
  2. Busca "ePadLink SigCaptureWeb SDK" o "WebSigner"
  3. Haz clic en "Añadir a Chrome"
  4. Confirma la instalación
🔗 Instalar desde Chrome Web Store

Mozilla Firefox

  1. Abre Firefox y ve a Firefox Add-ons
  2. Busca "ePadLink SigCaptureWeb SDK" o "WebSigner"
  3. Haz clic en "Añadir a Firefox"
  4. Confirma la instalación
🔗 Instalar desde Firefox Add-ons

Microsoft Edge

  1. Abre Edge y ve a Microsoft Edge Add-ons
  2. Busca "ePadLink SigCaptureWeb SDK" o "WebSigner"
  3. Haz clic en "Obtener"
  4. Confirma la instalación
🔗 Instalar desde Edge Add-ons

⚙️ Paso 4: Configurar la Extensión

Después de instalar la extensión:

  1. Habilita la extensión: Ve a la configuración de extensiones de tu navegador y asegúrate de que esté activada
  2. Permisos: Acepta todos los permisos necesarios
  3. Reinicia el navegador: Cierra completamente el navegador y ábrelo de nuevo
  4. Conecta el ePad: Asegúrate de que el dispositivo esté conectado y reconocido

🧪 Paso 5: Probar la Instalación

Una vez instalada la extensión, prueba que funcione correctamente:

✅ Página de Prueba: Abrir página de prueba del ePad

En la página de prueba podrás:

  • Verificar si la extensión está instalada
  • Comprobar la conexión del servicio
  • Probar la captura de firma
  • Ver logs detallados de debugging

🔍 Paso 6: Verificar en la Aplicación

Después de completar la instalación:

  1. Recarga la página de la aplicación
  2. Ve a la sección de entrega de solicitudes
  3. Selecciona un empleado para entregar
  4. Elige "Capturar desde ePad" en el modal de firma
  5. Haz clic en "Iniciar captura desde ePad"
💡 Tip: Si sigues viendo el mensaje "Extensión no instalada", abre las herramientas de desarrollador (F12) y revisa la consola para ver los logs de debugging.

❌ Solución de Problemas

Si la extensión no se detecta:

Verificaciones básicas:

  • ¿Está la extensión habilitada en el navegador?
  • ¿Se reinició el navegador después de la instalación?
  • ¿Está el ePad conectado y funcionando?
  • ¿Se instaló el software base del ePad?

Debugging avanzado:

Abre la consola del navegador (F12) y ejecuta:

console.log("Atributo documentElement:", document.documentElement.getAttribute("SigCaptureWebExtension-installed"));
console.log("Objeto SigCaptureWeb:", typeof window.SigCaptureWeb);
console.log("Elementos SigCapture:", document.querySelectorAll('[class*="SigCapture"], [id*="SigCapture"]').length);
